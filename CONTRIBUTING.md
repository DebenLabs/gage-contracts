# Contributing

This repository is generated from gage's private source at each release. **Pull requests are not merged here:** the next release would overwrite them. Open an issue instead.

- **A vulnerability:** never in a public issue. See [SECURITY.md](SECURITY.md).
- **A request:** open an issue with one of its forms: [List a token](../../issues/new?template=token-listing.yml) ([LISTING.md](LISTING.md)), [Open a vault](../../issues/new?template=vault-creator.yml), [Integrate with gage](../../issues/new?template=integration.yml) ([PARTNERS.md](PARTNERS.md)).
- **A question about using gage:** [docs.gage.cash](https://docs.gage.cash) or [support](https://gage.cash/support).

An issue here is intake and triage. The work happens in gage's private source, and the issue is closed with the Safe batch or transaction that settled it. Partners already in direct talks with gage don't need an issue.
